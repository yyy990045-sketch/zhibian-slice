# ADR-0003：对外类别统一为“知乎观点压力测试器”

状态：已接受
日期：2026-09-01

## 背景

“观点海域”适合承载海图、航线、浮标和灯塔的视觉记忆，但单独作为产品名称时，评委需要猜测产品做什么。当前主链的可验证价值是：用户先表态，沿知乎来源阅读对立材料，再记录自己的二次判断。

## 决策

所有对外入口统一使用“知辩｜知乎观点压力测试器”作为产品类别和主标题；“观点海域”保留为视觉隐喻和功能名。核心句统一为“先表态，再听社区，最后自己改判”。

## 取舍

- **只用“观点海域”**：视觉感强，但产品用途不够直白，评委首屏理解成本高。拒绝。
- **只用“立场分析/观点总结”**：直白，但会把知辩误解为普通摘要或裁判工具，削弱社区反方阅读和用户自主判断。拒绝。
- **类别直白 + 隐喻记忆**：首屏先解释是什么，再用海图形成记忆点，兼顾理解速度和辨识度。接受。

## 后果

- 首页、README、项目简介、项目广场和 Demo 统一讲“观点压力测试器”，减少不同材料之间的定位漂移。
- 演示重点从“展示一张漂亮海图”转为“展示一次可追溯的观点压力测试”。
- 规则聚类、OAuth 和官方直答的边界继续如实披露，不因包装改变产品能力声明。
