# ADR-0002：本次参赛主链不承诺 OAuth 个性化

状态：已接受
日期：2026-09-01

## 背景

知辩已经具备可公开体验的游客主链：真实知乎搜索、热榜与直答对照，来源绑定的观点海图与挑战，二次判断和分享成长卡。收藏夹校准等授权个性化需要公网回调、状态与签名校验、会话隔离、每用户令牌和隐私验收；当前用户数据接口明确保持禁用，公共主链已完成公网核验。

## 决策

本次黑客松提交冻结为“参赛主链”，不把 OAuth 收藏夹、关注或创作内容的个性化校准列为交付承诺、验收条件或宣传卖点。它统一归入“赛后增强”；在新的安全闭环完成前，相关接口继续返回明确禁用状态，入口只能呈现演示降级，不读取用户数据。

## 取舍

- **现在启用 OAuth**：能增加个性化和登录传播想象，但会把回调、令牌隔离、隐私和测试账号风险带进提交窗口，且当前实现尚未达到可安全承诺的完整度。拒绝。
- **保留为本次必做但标注未完成**：表面上保留创新方向，却会让评委把未完成的授权链误判为主流程缺口。拒绝。
- **冻结游客主链，OAuth 赛后增强**：保留清晰的社区价值和可复验 Demo，同时给后续个性化留出独立的安全验收边界。接受。

## 后果

- 计划书、演示脚本、项目广场文案和提交清单只承诺游客真实主链，不再把 OAuth 写成当前阶段待补交付。
- `/api/zhihu/me/*` 保持禁用是本次的安全边界，而不是失败的隐藏状态；收藏夹入口只能说明赛后方向。
- 赛后若恢复授权个性化，必须重新定义回调、会话、令牌、隐私和测试账号验收，并以新的 ADR 或后续决议替代本范围判断。
