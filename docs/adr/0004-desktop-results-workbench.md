# ADR-0004：桌面端采用双栏结果工作台

状态：已接受
日期：2026-09-01

## 背景

结果区原本把观点海图、成长卡和来源卡全部纵向单列。这样虽然在移动端安全，但在桌面端造成大量空白和过长滚动，评委难以在同一视野理解“观点结构 → 挑战与二次判断”的主链。

## 决策

桌面端结果工作台采用“左侧观点海图 + 右侧成长卡”的双栏结构，来源卡放在下方全宽作为证据层；移动端在窄屏断点恢复单列。海图和成长卡属于同一阶段的并行信息，来源卡保持完整宽度以承载长文本。

## 取舍

- **继续单列**：实现简单，但浪费桌面空间，主链被纵向滚动切断。拒绝。
- **三栏同时展示来源卡**：信息密度过高，长文本挤压核心判断动作。拒绝。
- **海图/成长卡双栏 + 来源全宽**：先呈现判断与挑战，再提供完整证据，兼顾首屏理解和来源可读性。接受。

## 后果

- 桌面端首屏结果高度降低，左右视觉重量更平衡。
- 来源卡仍然完整展示，不牺牲原文回看和可追溯性。
- 所有窄屏设备必须验证无横向溢出，并保持结果顺序为海图 → 成长卡 → 来源卡。
